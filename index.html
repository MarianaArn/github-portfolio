About

Technology with a clear operational purpose

My work is shaped by the idea that a successful IT solution should be understandable, testable, maintainable, and useful to the people who depend on it. My graduate studies have allowed me to connect software engineering, databases, cybersecurity, human-computer interaction, project management, and systems operations in one applied body of work.

My capstone, the Datacenter Deployment Tracking System (DDTS), grew from a real operational problem: rack deployment status was fragmented across spreadsheets, email, tickets, and manually prepared reports. I designed and implemented a focused web application that centralizes deployment records, enforces workflow sequencing, preserves audit history, and provides role-aware views for operational users.

Featured Project

Datacenter Deployment Tracking System

DDTS is a role-aware Flask web application designed to replace fragmented datacenter rack deployment tracking with one auditable workflow. The system manages deployments and racks, assigns technicians, protects role-specific actions, and enforces progression through Received, Racked, Powered, Data Cabled, Network Configured, and Validated.

The capstone demonstrates requirements analysis, architecture, database design, security controls, HCI decisions, automated testing, Linux deployment, configuration management, and professional technical documentation.
